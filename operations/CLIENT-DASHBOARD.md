# Read-only client dashboard

Entry point: Rastreamento → client → Visão do cliente. Administrators with can_view_financials can preview, enable, copy and deactivate one fixed link per client. The link is a bearer capability, intended for recipients chosen by the owner; no client login is required. The UI explicitly explains this before activation. Rayafit activation was separately confirmed by the user on2026-11-01.

The client landing page bypasses AuthProvider/App navigation and renders only aggregates: observed first contacts, origins, daily evolution, confirmed service/sale counts, unit counts, monthly lead goals when configured, and the client's advertising metrics. It has no write forms and no contact-level endpoint. It excludes lead names, numbers, CRM IDs, conversations/evidence, fees, agency financials and credentials. Dates/channel selection/theme are view controls only.

`wa_dashboard_links` is server-only, with no anonymous/authenticated table privileges. A 256-bit random token is stored as SHA256 for lookup and separately encrypted using AES-GCM with `dashboard:<client>` binding for administrator recovery. Link remains fixed across reloads/deactivation/reactivation. No expiry or rotation is currently configured. Invalid/disabled tokens get404; public actions derive client_id only from the matched row, ignore caller-supplied IDs and revalidate the link version after data acquisition. POST-only, exact Studio origin, no-store/no-referrer/noindex responses. Tokens live in the URL fragment, not query strings or server URLs. Meta media caches last up to120seconds per link/version/period, with token validation on every request. Database records are bounded to20000 per connection/table; oversized results fail explicitly rather than returning partial totals.

Counts remain first-observed contacts per WhatsApp connection; multi-connection totals are labelled accordingly. Public service counts retain partial-history warnings and never infer confirmed sales from an advertisement conversion. Google advertising metrics remain pending authorization. GA4 reporting, Instagram organic reporting and EVO are not newly connected by this feature.

Internal URL routing now stores client slug+UUID, internal/client view, WhatsApp tab, executive/acquisition/goals section, channel, unit and dates. Goals month and campaign/ad detail are also represented. Reload and browser history restore these states. ACLs remain server/database-enforced; changing an ID in the URL does not grant access.
